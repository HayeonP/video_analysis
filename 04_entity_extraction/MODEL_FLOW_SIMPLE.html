영상 분석은 이 순서로 돌아갑니다

현재 analyze_sintel.sh / analyze_frozen.sh의 기본 sampled 경로 · 2026-10-13

핵심: 영상을 장면으로 자르고 → 필요한 사진만 고르고 → 사진 속 대상을 찾고 → 같은 대상을 하나의 ID로 묶습니다.

어디까지 전체 프레임을 보나요?
① 샷 분할과 ② 샘플링은 원본 프레임을 읽습니다. ③부터는 ②에서 선택한 사진만 분석합니다. 사진 사이에 있었던 움직임을 새로 추론하거나 박스를 만들어 채우지 않습니다.

① 영상에서 샷을 나눕니다

모델: TransNetV2. 화면이 다른 장면으로 바뀌는 지점을 찾습니다. 예를 들어 실내에서 설산으로 바뀌면 샷 경계 후보가 됩니다.

실제 처리: 48×27로 줄인 영상에서 전환 확률을 계산하고, 기본 임계값 0.5와 최소 샷 길이 0.25초를 사용합니다. 페이드·검은 화면도 보정합니다. 원본 프레임이 빠지거나 겹치지 않게 MP4 샷과 shots.json을 저장합니다.

② 각 샷에서 분석할 사진을 고릅니다

방법: Farneback optical flow로 움직임을 계산하고 RGB 차이로 화면 변화를 계산합니다. 현재 코드는 SSIM을 사용하지 않습니다.

실제 처리: 폭 256의 작은 화면에서 카메라 움직임을 보정한 변화량을 누적합니다. 변화가 많으면 촘촘하게, 적으면 드물게 선택합니다. 기본 목표 범위는 초당 1~10장이고, 급변·시작·끝 보호 규칙도 적용됩니다. 선택 사진, 원본 프레임 번호, 다음 사진까지 유지할 시간을 저장합니다.

③ 선택한 사진 속 대상을 찾습니다

모델: YOLO11x. 사람·동물·물체의 위치를 사각형 박스로 표시합니다. 작은 대상은 같은 사진의 일부를 확대하여 추가 탐색합니다.

출력: “이 사진의 이 위치에 대상이 있다.” 아직 누구인지, 앞 샷과 같은 대상인지는 모릅니다. 검출에 실패한 대상은 이후 단계에서도 완전히 복구된다고 보장할 수 없습니다.

④ 사진 사이의 박스를 임시로 연결합니다

모델: DINOv2-small. 각 박스의 외형을 비교 가능한 숫자 벡터로 바꿉니다.

실제 처리: 외형 유사도, 박스 겹침, 실제 경과 시간을 함께 사용해 일대일로 연결합니다. 이 연결을 트랙이라고 합니다. 오래 보이지 않거나 모습이 급변하면 연결을 끊습니다. 잘못 이어진 것으로 의심되는 구간은 나누어 다음 단계에 넘깁니다. 현재 sampled 경로는 BoT-SORT나 OSNet을 사용하지 않습니다.

⑤ 한 샷 안에서 같은 대상을 정리합니다

모델: Qwen3-VL-8B-Instruct. 선택한 장면 사진과 트랙별 확대 사진을 함께 봅니다.

질문: “이 트랙들은 같은 사람인가? 이 박스는 사람 전체인가, 손인가, 들고 있는 물건인가?” 끊어진 트랙을 같은 대상으로 묶고, 손과 몸의 소유관계나 잘못된 분류를 검토합니다. 추적 대상이 바뀐 의심 구간은 먼저 나누고, 대상만 확대한 비교로 외형을 확인합니다(추가 최대 4회). 얼굴이 보이지 않는다는 이유만으로 이미 확인한 연결을 폐기하지 않습니다.

출력: 샷 안에서만 유효한 Local ID. 예: shot_0001:L01. 다른 샷의 L01과 자동으로 같은 대상이 되는 것은 아닙니다.

⑥ 샷 사이 연결을 만들고, 오류만 고칩니다

연결: DINO·선택적 얼굴 특징으로 비교 후보를 찾고 Qwen3-VL-8B-Thinking이 두 후보의 여러 모습을 비교합니다. 후보가 소진되면 종료하며 안전 상한은 재시도 포함 96회입니다. 먼저 생각 과정을 1,024 토큰으로 제한해 비교하고, 미확정인 샷 간 비교만 같은 이미지로 긴 추론을 한 번 추가합니다. 추가 검토도 96회 총상한에 포함하며, 재개해도 상한은 늘어나지 않습니다. 같은 옷이나 색 하나만으로 연결하지 않습니다.

외형·이름: Qwen Instruct가 의심되는 추적 구간을 확대해 확인합니다(최대 4회). 확인된 외형 모순이 있는 구간만 분리합니다. 단순히 자세가 바뀌거나 얼굴이 가려졌다는 이유로 기존 연결을 모두 끊지 않습니다. 이름은 별도로 확인한 외형에 근거하며 긴 설명문을 우선하지 않습니다.

같은 프레임의 충돌: Instruct가 원본 장면의 여러 박스가 한 몸의 부분인지, 서로 다른 몸인지 확인합니다. 이전 ID를 바꾸거나 겹침이 약한 몸들을 합치려는 판단만 Thinking으로 다시 확인합니다. 두 모델은 순서대로 적재합니다. 새 미확정 사람 ID가 생기면 참조 인물 사진 없이 주변 영역을 확대해 몸의 수를 다시 확인합니다. 그림자는 별도 사람으로 세지 않고, 같은 몸의 확대 박스는 하나로 묶습니다.

출력: 같은 몸이라고 확인한 박스는 그 프레임에서 하나의 외곽 박스로 통합합니다. 원래 박스·검토 이미지·판단 근거를 모두 보존합니다. 서로 다른 몸은 별도 ID이며, 동일 ID가 한 프레임에 여러 번 남으면 출력 검증에 실패합니다.

기본 전략은 linked입니다. 기존 5회 compact는 실험 옵션으로 남겨 두었습니다. 기존 결과 복구는 샷 분할·검출·전역 연결을 재사용하므로 새 영상 전체 처리와 시간을 구분합니다.

⑦ 통일된 ID로 장면을 설명합니다

모델: Qwen3-VL-8B-Instruct. 앞에서 얻은 관측과 Global ID를 기준으로 요약을 정리합니다. “어느 샷의 누가 무엇을 했는지”가 같은 ID로 이어지게 합니다. ID 참조 오류나 근거 부족은 검증·품질 기록에 남깁니다.

⑧ 결과를 저장하고 확인합니다

Global Entity 목록, 샷별 등장 정보, 요약, 검증 결과, 선택 프레임 영상, 실행 시간을 저장합니다. 영상은 선택한 사진을 다음 선택 시각까지 유지하여 원래 재생 시간을 맞춥니다. 부드러운 원본 영상에 매 프레임 박스를 추적한 결과는 아닙니다.

다른 영상에도 적용되나요?

분석 알고리즘에 Sintel 인물명이나 정답 연결을 고정하지 않았습니다. Sintel/Frozen 스크립트는 입력 파일과 결과 이름만 다르게 지정합니다. 평가용 Sintel 정답은 분석에 넣지 않습니다. 기본 실행은 웹 소개문도 사용하지 않습니다.

다만 “다른 영상에도 실행 가능”과 “모든 장르에서 정확”은 다릅니다. 빠른 편집·작은 얼굴·가림·동일 복장·애니메이션 등에서는 검출과 연결이 어려울 수 있습니다. 현재 전처리는 일정 FPS(CFR) 입력을 요구합니다.
