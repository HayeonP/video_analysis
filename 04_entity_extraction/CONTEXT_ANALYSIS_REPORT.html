전체 개념: 사진첩과 장면 메모를 함께 본다

각 샷에서 찾아낸 대상을 먼저 임시로 연결한 다음, 불명확한 관측을 선명한 참조 사진·전체 영상의 흐름·반복 등장과 비교해 재배정합니다. 이전에 붙인 이름을 그대로 믿지 않습니다.

1 · 중학생: 사진을 보고 출석부를 고치는 과정

여행 사진 17장을 순서대로 본다고 생각해 보세요. 한 사람은 가까이 찍혔을 때 붉은 머리가 보이지만, 멀리 찍혔을 때는 머리가 안 보일 수 있습니다. 작은 사진만 보면 다른 사람으로 착각하기 쉽습니다.

  1. 임시 출석부: 사진마다 보이는 사람과 동물을 찾고, 비슷한 것끼리 임시 번호를 붙입니다.
  2. 참조 사진첩: 각 번호에서 선명한 사진 여러 장을 꺼냅니다. 얼굴뿐 아니라 옷과 장비도 비교합니다.
  3. 앞뒤 내용: 샷을 시간순으로 보며 누가 무엇을 하는지 한국어로 적고, 장면이 이어지는지 바뀌는지도 적습니다.
  4. 번호 고치기: 작은 사진의 인물을 참조 사진과 다시 비교합니다. 작은 생물도 밝은 배 쪽 모습과 어두운 등 쪽 모습이 같은 개체일 수 있는지 확인합니다.
  5. 마지막 검사: 하나의 몸이 두 사람으로 세어지거나, 서로 다른 몸이 한 사람이 되지 않았는지 검사합니다.

많이 나온 인물이니까 무조건 주인공이라고 합치는 것은 아닙니다. 많이 등장했다는 사실은 먼저 비교할 이유입니다. 옷·도구·체형과 앞뒤 행동도 맞아야 합니다. 읽을 수 없는 얼굴을 ‘노인 얼굴’로 상상하면 안 됩니다.

모델마다 맡은 일이 다릅니다

TransNetV2는 영상에서 장면이 바뀌는 지점을 찾습니다. YOLO11x는 선택한 사진에서 사람·동물·물체의 위치에 사각형을 그립니다. DINOv2-small은 사각형 안의 모습을 비교할 수 있는 숫자로 바꿉니다. Qwen3-VL-8B-Instruct는 사진 속 대상의 외형과 상황을 설명하고, Qwen3-VL-8B-Thinking은 여러 사진과 장면 흐름을 함께 보고 같은 대상인지 판단합니다.

예를 들어 YOLO가 “여기에 대상이 있다”고 찾으면, DINO가 “이쪽 사진과 비슷하다”고 후보를 제안하고, Qwen이 사진과 근거를 보고 연결 여부를 판단합니다. 마지막으로 일반 프로그램 코드가 ID 충돌을 검사합니다.

3 · 컴공 학부생: 데이터와 호출 순서

3.0 · 구현 기준 모델 사용 상세

처리 범위: TransNetV2는 샘플링 이전에 원본 영상의 전환을 찾습니다. 아래 YOLO·DINO·Qwen의 04 입력 이미지는 선택된 프레임에서 가져옵니다. Qwen은 선택 프레임 279장을 매번 전부 받는 것이 아니라, 단계별로 고른 장면 사진·대표 crop·검토 프레임을 받습니다.

YOLO11x → DINOv2: shot_tracking.py의 검출 기본 입력 크기는 1280, confidence 하한은 0.08, NMS IoU는 0.72입니다. 조건부 작은 대상 탐지는 640 크기 타일, 겹침 25%, 프레임당 최대 6개입니다. 같은 선택 프레임에서 잘라낸 영역이므로 추가 시간 프레임 분석이 아닙니다. 이번 기록은 전체 화면 279회, 타일 1,122회입니다. 각 박스 crop은 DINO 전처리기를 거쳐 최대 16개씩 묶어 실행하며, last_hidden_state[:, 0] 벡터를 L2 정규화합니다. 이 벡터와 박스 위치·시간 간격으로 sampled 추적을 수행하고, 기존 벡터를 전역 후보 검색에 재사용합니다.

Qwen 실행 방식: 두 모델 모두 이번 기록에서 NF4 4bit 가중치와 BF16 연산을 사용했습니다. Instruct와 Thinking은 서로 다른 작업에 쓰는 두 모델이며, Thinking을 매 프레임 실행하지 않습니다. 요청은 지시문 + 번호가 표시된 이미지 + 구조화된 입력으로 구성하고, 응답은 JSON 스키마와 대상 ID 범위로 검증합니다. 모델이 제안한 병합·재배정은 이후 코드의 충돌 검사까지 통과해야 적용됩니다.

3.1 · 어떤 이미지를 보여주나

각 참조 그룹의 local 구성원별 최대 박스 면적을 구합니다. 그룹 내 최대값의 30% 이상인 구성원에서 최대 6개를 시간순으로 고르고, 각 구성원의 대표 사진을 같은 크기로 보여줍니다. 기존에 잘못 연결된 매우 작은 관측이 참조 사진이 되어 자기 자신을 정답처럼 강화하는 일을 줄이기 위한 방법입니다. 면적은 선명도의 근사치여서 큰 손이나 흐린 몸도 통과할 수 있습니다.

인물 재검토 단위는 같은 샷·같은 임시 ID의 local 묶음입니다. 그 묶음의 최대 박스 면적이 프레임의 15% 미만인 경우를 검토합니다. 동물은 local 개체를 개별 단위로 다룹니다. 단 한 샷에만 등장하는 기존 그룹의 관측에 대해, 여러 샷에 등장한 다른 그룹에서 시각적으로 가장 닮은 local 관측을 찾습니다. 기존 그룹 전체를 이동시키지 않으므로 작은 생물과 큰 동물의 일부가 섞여 있으면 서로 분리될 수 있습니다.

인물 호출에는 각 샷에서 양끝을 제외한 프레임에서 시간순으로 선택한 세 장면을 추가하여 전체 흐름과 한국어 요약을 함께 검토합니다. 동물 호출에는 앞 호출에서 작성한 해당 샷의 전환 종류·한국어 전환 근거와, 서로 유사한 시점의 실제 사진 쌍 최대 3행을 전달합니다. 기존 요약의 ‘새’ 같은 잘못된 종 이름이 판단을 지배하는 현상이 있어, 이 호출에는 전체 요약 문장 대신 전환 기억만 전달합니다. 모두 기존 선택 프레임 안에서 가져옵니다.

3.1.1 · 반복 등장과 유사 사진 검색의 정확한 규칙

인물 사전 확률: 박스 면적이 화면의 15% 이상인 관측을 가진 서로 다른 샷 수를 센 뒤, 최소 3샷에 등장하고 전체 참조 지지의 60% 이상을 차지하는 후보를 중심 인물 가설로 제공합니다. 대상 박스 짧은 변의 최대 길이가 64픽셀 미만이면 얼굴로 나이·대머리·수염을 판정하지 말고, 이 가설과 복장·도구·장면을 함께 비교하도록 명시합니다. 이 조건은 자동 병합 규칙이 아니라 VLM 입력의 우선 후보입니다. 이번 마지막 인물 연결은 선명한 얼굴 인증이 아니라 이런 문맥 추정에 해당합니다.

경계 연속성: 서로 이웃한 샷의 끝·시작 2프레임 이내 실제 관측에서 박스 IoU ≥ 0.9, 전체 이미지 유사도 ≥ 0.98, 크롭 유사도 ≥ 0.97인 쌍을 제안합니다. 유사도는 축소 RGB의 평균 절대 차이를 1에서 뺀 값입니다. 시간 간격도 제한하고 실제 사진을 VLM에 보여줍니다. tracker 미확정이어도 검출 신뢰도 ≥ 0.6인 실제 검출은 이 문맥 후보 단계에서만 허용합니다. 보간 박스는 사용하지 않습니다.

동물 검색: 이미 계산된 대표 관측의 DINO 벡터 평균을 정규화합니다. 서로 다른 그룹에서 상호 가장 가까운 쌍이며 코사인 유사도 ≥ 0.75, 양쪽 모두 2위 후보와의 차이 ≥ 0.035인 경우만 검토합니다. 동시 등장 충돌이 있는 목적 그룹은 제외합니다. 이어서 각 실제 관측의 벡터를 비교하여 가장 비슷한 시점의 사진 쌍 3개를 선택합니다. 몸의 큰 박스만 고르는 방식보다 얼굴끼리 비교할 가능성이 높습니다.

동물 결정: 높은·유일한 시각 유사성, 기존에 반복 관측된 후보, 물리적 충돌 없음, VLM의 해부학적 호환성 확인을 모두 요구합니다. VLM은 카메라 거리·배경·표정만 다르다는 이유로 다른 종이나 몸이라고 판단하지 않도록 지시받습니다. 이 결합 규칙 역시 확률적인 개체 추정입니다. 같은 종의 닮은 개체가 교대로 나오는 영상에서는 추가 검증이 필요합니다. 일부가 이동한 뒤 남는 옛 동물 그룹은 종 이름을 확정하지 않고 ‘미확정 동물 관측’으로 표시합니다.

3.2 · 모델의 답변을 실제 데이터에 적용하는 방법

응답은 assignments: U → G 또는 uncertain, 대상별 한국어 이유, 샷별 요약과 전환, 선택적인 한국어 라벨로 구성합니다. U는 이 요청 안의 임시 대상 번호이며 기존 Global 번호와 무관합니다. 참조 G는 기존 Global ID지만 그 이름은 입력에서 숨깁니다. 번호의 앞자리 0 차이는 유일한 U로 대응되는 경우에만 기계적으로 정규화합니다.

  1. 요청한 U가 빠짐없이 한 번씩 들어 있는지, 기존 참조 ID 또는 uncertain만 반환했는지 검사합니다.
  2. 동시에 분리되어 관측된 몸을 같은 ID로 붙이는 답은 거부합니다. 재검토하지 않는 고정 관측과의 충돌도 검사합니다.
  3. 첫 호출은 모든 샷의 한국어 요약·전환을 순서대로 요구합니다. 동물 호출은 한국어 전환 기억을 입력으로 사용하며 새로운 요약을 만들지 않습니다.
  4. 확정 답만 local → Global 매핑에 반영합니다. uncertain은 기존 배정을 유지하고 불확실한 결정으로 기록합니다.
  5. 새 매핑으로 Global 구성원을 재구성하고 사용되지 않는 ID는 제거합니다. 이미 같은 몸이라고 확인한 physical_groups가 쪼개지면 저장을 실패시킵니다.
  6. 독립적으로 확인한 인물 외형 투표로 라벨을 다시 정합니다. 이름만 고치는 과정은 구성원 연결을 바꾸지 않습니다.

출력 샷의 summary와 initial_summary 모두 한국어 장면 기억에서 가져옵니다. 예전 원문은 local 데이터의 source_summary에 진단용으로 보존합니다. 정확한 사건 시각을 새로 확인하지 않았으므로 events는 빈 목록입니다. 전환 판단과 근거는 뷰어에 별도로 표시합니다.

3.3 · 호출 수·캐시·실패 처리

전역 후보·외형·몸 보정·문맥 재배정의 실제 생성 횟수를 합쳐 기본 10회로 제한합니다. 재시도도 포함됩니다. 17샷의 이 영상에서는 기본적으로 후보 4회 + 외형 1회 + 몸 보정 3회 + 문맥 2회를 계획합니다. 실제 횟수는 아래 로그를 기준으로 확인해야 합니다. 앞단의 샷별 local 추출 호출은 이 10회에 포함되지 않습니다.

몸 보정은 문맥용 2회를 먼저 예약한 뒤 남은 횟수에 맞춰 여러 프레임을 한 요청으로 묶습니다. 한 요청은 최대 16프레임입니다. 전체 요청량이 상한을 넘으면 대상 일부를 몰래 버리지 않고 실패합니다. 32개를 넘는 문맥 후보 또는 12개를 넘는 동물 비교 쌍 역시 현재는 입력 분할이 필요합니다. 따라서 긴 영상이나 많은 출연자가 등장하는 영상에 무조건 10회를 보장하는 구현은 아닙니다.

정확한 입력·이미지·모델·생성 옵션이 같은 응답만 캐시로 재사용됩니다. 모델 파일 캐시와 추론 응답 캐시는 다릅니다. 새 출력 폴더에서 실행하면 이전 전역 목록이나 테스트 정답을 읽지 않습니다. 정상 재개에서는 실제 생성 누계가 이어지므로 상한이 초기화되지 않습니다.

모델 JSON이 마지막 바깥쪽 닫는 중괄호 하나만 누락했을 때는 해당 기호만 보완합니다. 불완전한 문자열이나 값, 없는 필드·판단을 만들어 채우지 않습니다. 문법 보완 뒤에도 스키마와 전체 대상 범위 검증을 통과해야 합니다. 한국어 검사는 한글 존재와 따옴표 밖 영문 단어를 검사하는 규칙이므로 의미·문법의 완전한 품질 보장은 아닙니다.
