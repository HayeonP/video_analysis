04 / ENTITY EXTRACTION
처리 흐름Qwen 호출모델 역할결과물

수정된 처리 방식 · 실제 분석 검증 전

중복 박스를 정리하고,
샷 사이의 같은 대상을 연결합니다.

얼굴·몸·대상 외형으로 기본 연결을 먼저 만듭니다.
Qwen이 이름과 장면 문맥을 검토하며, 응답이 실패해도 기존 외형 연결은 보존합니다.

입력: 03의 adaptive 조각 영상과 선택 시각 → 출력: entity 목록 · 샷별 등장 여부 · 박스 영상

대상 이름·개수는 입력에서 추론합니다. 특정 영화의 샷 번호나 등장인물을 규칙으로 지정하지 않습니다.

왜 다시 수정했나요?

이전 anchored 결과는 전체 목록 응답에서 참조 트랙 수의 JSON 제약을 위반해 검증이 실패했고, 56개 항목이 모두 미확정으로 남았습니다. 이번에는 Qwen 이전에 외형 연결을 만들고, 중복 박스 융합과 최종 ID 관계 검토를 추가합니다. 이번 수정 후 실제 분석·테스트는 추가 실행하지 않았으므로, 정확도 개선은 새 결과에서 확인해야 합니다.

01 / FOUR STEPS

앞에서 뒤로, 네 단계로 끝냅니다

단계를 누르면 입력과 처리 내용을 볼 수 있습니다.

⌕
멀리 있는 작은 대상화면 높이에 비례한 크기 기준으로 확대 검출합니다. 기본 대상은 사람이며 설정으로 바꿉니다.
≋
한 대상에 여러 박스겹침·외형·샷 안의 반복 관측을 확인하고, 전역 ID를 만들기 전에 융합합니다.
⇄
샷을 넘나드는 동일 대상외형으로 먼저 연결하고 Qwen이 문맥과 분리된 ID의 통합 가능성을 검토합니다.

위 항목은 개선을 위한 처리 방법입니다. 작은 대상의 검출이나 동일 인물·생물의 정확한 통합을 보장하지는 않습니다.

02 / FIXED ORDER, LIMITED CALLS

목록 설명 1회 → 배치 배정 → 최종 관계 검토 1회

Python이 외형 연결, 관측 근거, 실행 순서와 호출 예산을 관리합니다.

Agent 구조인가요?

같은 Qwen 모델이 전체 목록 설명 → 관측 배정 → ID 관계 검토의 세 역할을 맡습니다. Python이 정해진 순서와 횟수로 호출합니다. 자율적으로 계획을 늘리는 멀티 Agent 구조는 아닙니다.

입력 길이에 맞춰 묶고, 기본 계획 최대 7회

기본 최소 4개 샷 단위, 최대 5개 배치. Qwen 호출 전 외형 연결과 실제 참고 트랙이 준비됩니다.

호출 1 · 전체 목록 설명
실제 V-ID + 참고 crop + 장면 → 짧은 이름 · 종류 · 외형
참고 트랙의 소속은 외형 연결 결과에서 가져옵니다.
배치 1앞부분
배치 2시간순
배치 3시간순
배치 4시간순
배치 5뒷부분
배치마다 실제 관측과 비교
현재 트랙 + 기본 목록·참고 이미지 + 장면 정보
트랙별 판단
기준 개체에 배정 / unknown: 누구인지 보류 / reject: 오검출 제외
↓
마지막 호출 · 카탈로그 관계 검토
미해결 배정 + 분리된 ID의 동일성 검토
통합 제안 → 외형·동시 등장 검사 → 적용 또는 보류

대상 수는 강제하지 않습니다. Qwen이 참고 트랙의 소속이나 검출 기록을 새로 만들 수 없습니다. 검토 한도를 넘기거나 응답 검증에 실패하면 외형 추정을 보존하고 미검토 상태를 기록합니다.

OFF에서는 위 Qwen 호출 없이 외형 기반 연결로 결과를 만듭니다.

실제 생성 호출의 절대 상한
8 회 이내 / 분석 작업
12345678

기본 계획: 목록 설명 1회 + 배치 최대 5회 + 관계 검토 최대 1회 = 최대 7회.
8번째 칸은 남는 예산이며, 반드시 실행하지 않습니다.

중단 후 재개해도 같은 예산 유지
생성을 시작하면 한 회를 사용하며, 실패·메모리 부족·재시도도 포함합니다. 캐시 응답은 차감하지 않습니다. 예산이 없으면 추가 추론을 멈추고 외형 추정과 미검토 경고를 보존합니다.

프레임별 Qwen 검출, 샷별 역방향 루프, 모든 후보 쌍의 반복 검토는 기본 경로에서 실행하지 않습니다.

그림은 기본 설정입니다. 기본 장면 프레임 최대 40개, 배치당 트랙 최대 32개이며 설정으로 조정합니다. 8회 호출은 계산 예산이며, 임의 길이 영상의 모든 대상을 검토한다는 보장은 없습니다. 실제 호출 수·소요 시간은 실행 기록을 확인하세요.

03 / MODEL ROUTING

박스는 YOLO, 외형은 특징 모델, 문맥은 Qwen

얼굴이 안 보이면 얼굴 특징은 생략합니다. 머리색이 안 보인다는 이유만으로 다른 사람이라고 확정하지 않습니다.

모델언제 사용하는가무엇을 만드는가모드
YOLO11x · 변경 가능대상 검출기본 입력 크기 1280으로 전체 화면 검출. 확대 타일 최대 6개에서 작은 대상 추가 검출대상 박스·검출 클래스·신뢰도기본 신뢰도 0.25. 타일 대상 기본값은 사람, 추가 박스 높이는 화면 높이의 9% 이하. 확대 클래스·수·크기는 설정 가능ON + OFF

검출 모델의 학습 클래스가 모든 대상을 표현하지는 못합니다. ON에서는 Qwen이 관측 이미지를 보고 이름과 종류를 판단합니다. 이름이 같아도 같은 개체라는 뜻은 아닙니다.

중복 박스와 서로 다른 대상은 어떻게 구분하나요?

먼저 임시 샷 내부 트랙을 구성해 여러 프레임에 걸친 중복 근거를 확인하고 융합합니다. 이어 같은 프레임의 중복 관측을 정리하고 깨끗한 트랙을 다시 만듭니다. 접촉하거나 겹친 서로 다른 대상은 유지해야 하므로 박스의 겹침만으로 합치지 않습니다.

외형 연결은 얼굴·몸·DINO의 긍정적 근거를 사용합니다. 여러 트랙을 합칠 때도 묶음 전체의 동시 등장과 신뢰할 수 있는 얼굴 충돌을 확인합니다. 비슷한 옷을 매개로 연결이 끝없이 번지는 것을 줄이기 위해 대표 모습이나 여러 관측의 지지가 필요합니다.

미확정과 응답 실패는 어떻게 표시하나요?

단독 트랙은 새로운 실제 개체로 확정한 것이 아니라, 아직 다른 관측과 연결하지 못한 상태입니다. 약한 단일 관측도 기본적으로 보존합니다. Qwen은 unknown과 명확한 오검출 reject를 구분하고, JSON 오류나 호출 실패 시 기존 외형 추정을 유지합니다. 실패·검토 범위·불확실성은 anchored/quality.json과 결과 상태에 남기며, 검토 성공으로 표시하지 않습니다.

다른 영상에는 어떤 설정을 바꾸나요?

config.default.json을 복사해 --config로 지정합니다. detector는 검출, tracking은 샷 내부 연결, fusion은 중복 융합, visual_association은 샷 사이 외형 연결, matching은 Qwen 검토량, filtering은 약한 관측 처리, class_kinds는 검출 클래스의 대상 종류를 설정합니다. 수치 기준은 초기 휴리스틱이며, 정확도가 보정된 확률값은 아닙니다.

전체 박스 영상

원본 시각에 맞춘 adaptive 영상에 박스와 ID 표시. ON/OFF 비교 영상도 저장합니다.

adaptive_entities_full.mp4
./run.sh --input inputs/your_video --qwen-max-calls 8
기본 출력: outputs/your_video_entities
./visualize.sh → 최근 완료 결과

ON과 OFF는 같은 입력 샘플·YOLO 후보를 공유합니다. OFF는 Qwen을 호출하지 않습니다. 두 결과의 ID 번호는 독립적입니다.

통합·분리 판단의 근거 확인

observation_fusion.json과 track_fusion.json에는 중복 박스·트랙 융합 근거, anchored/visual_association.json에는 샷 사이 외형 연결과 거절 근거, anchored/quality.json에는 실패·미검토 경고를 저장합니다. 대상 수가 줄었다는 사실만으로 정확도가 좋아졌다고 판단하지 않습니다.

입력·시간축·캐시

입력은 03의 summary·samples 메타데이터와 adaptive 영상입니다. 임의 MP4 폴더를 직접 읽는 형식은 아닙니다. 전체 영상으로 연결할 샷은 같은 FPS와 해상도를 사용해야 합니다. 입력 경로를 생략하면 inputs 아래 후보가 정확히 하나일 때 자동 선택합니다.

원본 시각과 이미지의 표시 유지 구간을 보존하며, 03에서 생략한 원본 프레임까지 다시 분석하는 것은 아닙니다. 일치하는 검출·특징·Qwen 응답 캐시는 재사용합니다. 실제 시간은 캐시·검출량·하드웨어에 따라 달라집니다. 뷰어는 outputs/latest_run.json의 최근 완료 결과를 열고, 완료 기록이 없으면 이 설명을 표시합니다.

04_ENTITY_EXTRACTION · 중복 융합 + 외형 기본 연결 + 제한된 Qwen 검토 · 이번 수정 후 테스트·분석은 추가 실행하지 않았습니다. 이전 검사 수는 이번 정확도의 증거가 아닙니다. 버튼은 분석을 시작하거나 결과를 변경하지 않습니다.
